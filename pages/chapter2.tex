\chapter{文献综述}

\section{预期共识度量}
投资者的预期指的是其对于某一只证券未来表现的看法。
而预期共识，就是市场中的全部投资者对于某一只证券预期的整体水平。
想要深入探究预期共识效应，核心在于度量个体投资者对于某一个证券的预期水平。  
在传统的金融实证研究中，直接测量单个投资者的预期比较困难，
主流的方法大多通过间接方式衡量投资者整体预期，
包括宏观预期、代理指标、分析师预期分歧和文本分析\cite{唐国豪2025投资者预期协同}。
然而，这些方法都存在缺陷。

宏观预期指标一般通过调研、统计等方式计算得出，
反映了市场整体预期和情绪水平。
典型的宏观预期指数有密歇根大学消费者信心指数、MM经济预期指数等。
Lemmon等学者曾使用这类指数作为投资者乐观程度的代理变量\cite{lemmon2006consumer}，分析其对小市值股票溢价的影响。
但是宏观预期指标只能体现全市场的整体趋势，
无法识别单只证券的预期共识效应。

代理指标使用市场中的交易数据间接衡量投资者预期共识水平。
例如，朱宏泉等学者\cite{朱宏泉2016异质信念}采用“未预期到的换手率”，
动态刻画个股层面的预期共识变化，
该方法能剔除惯性交易、流动性需求等无关噪声；
孟庆斌等学者\cite{孟庆斌2018卖空机制}则使用卖空量衡量悲观预期。
卖空行为集中出现，往往反映投资者整体持负面预期。
然而，此类指标也存在明显的局限性，
其中往往存在较多噪声和信息重叠，无法精确地衡量投资者的预期水平。

分析师预期指标则是通过汇总专业分析师的预测结果，近似反映投资者预期共识。
例如，Diether等学者曾使用分析师盈余预测的均值作为指标，
衡量预期共识水平\cite{diether2002differences}，
Anderson等学者则通过分析师长期盈余增长预测的平均水平，
衡量共识强度\cite{anderson2005heterogeneous}。
但分析师群体的局限性非常明显：
首先，分析师的数量较少，且专业水平强，与散户投资者存在系统性差异，容易产生代表性偏差，其分析难以体现个体投资者预期；
此外，分析师预测受自身利益、行业压力等因素影响\cite{伍燕然2012分析师预测偏差}，其分析可能存在一定的偏误；
最后，分析师一般集中分析高市值、流动性强的证券，往往忽视小盘股。

文本情绪分析法指的是通过挖掘文本数据，提取情绪倾向，聚合形成预期共识。
部慧等学者利用股评文本构建投资者情绪指数\cite{部慧2018股评投资者情绪}，
万海远等学者通过企业调研文本与政策文本，分析企业预期变动\cite{万海远2024税收政策}，
均试图通过文本聚合捕捉市场共识。
但此类方法在当前的应用还存在较多局限性，如文本数据量过于庞大、
信息密度较低、数据收集过程复杂等。

随着机器学习和人工智能技术的发展，Agent的使用为刻画投资者预期提供了全新的视角。
Hornik等学者在其经典研究中证明了多层感知机（MLP）可以逼近任意连续函数\cite{hornik1989multilayer}。
因此，基于神经网络的Agent可以模拟投资者在真实市场中对于信息的处理和决策过程，从而较好地刻画单个投资者预期。
投资者的信念受其获取的信息\cite{sims2003implications}以及对信息解读\cite{daniel1998investor}\cite{hong2007disagreement}过程的影响。
对于Agent而言，其输入和解读的方式都可以通过调整神经网络参数的方式进行模拟，从而更贴合真实投资者的行为。
唐国豪等学者\cite{唐国豪2025投资者预期协同}通过多个神经网络，
构建了投资者预期协同度量模型，使用不同初始化参数的多层感知机模拟单个投资者的预期。
因此，使用Agent模拟单个投资者，在理论和实践上均有可行性，为解决预期共识度量问题提供了新的思路。

综合来看，现有预期共识度量方法虽为相关研究提供了重要支撑，但均存在难以规避的缺陷，
无法实现对个体投资者预期形成与个股层面预期共识的精准刻画。
随着机器学习与Agent技术的发展，通过智能体模拟投资者信息处理与决策过程成为可行路径，
为突破传统度量局限、构建更精准的预期共识度量体系提供了全新思路，
也构成了本文研究的重要出发点。

\section{预期共识定价效应}

关于预期共识的定价效应，存在两种不同的解释。
一种解释认为，预期共识源于投资者的集体情绪，引发错误定价。
另一种解释认为，投资者对于共同信息的解读形成了一致预期，降低了信息不对称程度，提高定价效率。
同时，不同市场的融资融券制度是影响预期共识定价效应的重要因素，
融资融券可以通过改善信息效率等方式，影响预期共识的定价效果。

Miller在1977年提出的分歧定价理论为预期共识研究奠定基础。
在卖空约束下，悲观投资者无法充分表达观点，
资产价格主要由乐观信念主导，预期分歧越大、共识程度越低，股价高估越严重，
未来收益越低。这一理论构成了两类共识效应的共同起点\cite{miller1977risk}。
情绪型共识以投资者乐观情绪趋同为核心。
Greenwood和Shleifer基于直接调研数据发现，
市场一致乐观的情绪型共识会推高当前股价并导致未来收益走低，
其本质是情绪驱动的错误定价\cite{greenwood2014expectations}；
信息有效型共识则强调信息收敛与风险定价效率。
Easley和Jarrow、Verrecchia等学者的研究指出，
只有基于信息趋同形成的共识能够降低信息不对称、减弱定价噪音，使资产风险更充分地暴露\cite{easley1983consensus}\cite{verrecchia2001essays}。
陈国进等学者基于中国市场，发现投资者的预期分歧越大，预期共识越低，股票未来收益越低\cite{陈国进2008异质信念与盈余惯性}。
唐国豪等学者进一步证实，
信息驱动下的预期协同度越高，错误定价水平越低，股票风险调整后收益越高\cite{唐国豪2025投资者预期协同}。

2010年，中国A股融资融券制度正式实施，放松了市场的融资融券约束。
大量学者基于该事件，检验了预期共识的定价机制。
王永钦等学者将融资融券制度改革作为准自然实验，
发现融资融券放松后，投资者的情绪表达更充分\cite{王永钦2026杠杆信息与流动性}。
顾琪、王策等学者发现，
融券约束会导致投资者无法充分发掘公司信息，导致定价效率降低\cite{顾琪2017卖空摩擦与股价同步性}。
褚剑和方军雄通过实证分析，发现在我国当前的金融市场中，融资数量远大于融券，导致了投资者的乐观预期更集中\cite{褚2019margin}。

整体而言，融资融券约束放松通过改善信息传递效率、
降低预期分歧，促进信息有效型共识形成，进而强化其定价效应。
现有文献多基于宏观或加总指标展开研究，
缺乏从个体预期形成到共识聚合的微观基础。本文采用多Agent模拟个体投资者预期，
能够更精准地识别信息有效型共识的定价效应与融资融券机制。

\section{基于Agent的实验金融研究}  
随着AI技术的发展，Agent已被广泛应用于实验金融领域，
为投资者行为模拟与交易决策研究提供了新的技术路径\cite{ahmed2022artificial}。
现有相关研究中，Agent投资者行为模拟与强化学习交易框架为本文研究奠定了理论与方法基础。

在投资者行为模拟方面，Agent凭借高灵活性被大量用于复刻真实市场中个体投资者的交易过程。
Henning 等学者利用大规模 Agent 模拟市场交易行为，发现 Agent 决策呈现 “教科书式理性”，较少出现泡沫等非理性偏差\cite{henning2025llm}；
AI-Hedge Fund 项目通过构建多风格 “投资大师” 智能体，以协作模式生成投资建议，丰富了多Agent 决策模式\cite{virattt2025aihedgefund}；
TwinMarket 系统则面向 A 股环境，采用多 Agent 模拟散户预期互动与情绪传染，进一步揭示了行为金融视角下的资产价格形成机制 \cite {yang2025twinmarket}。

在决策优化方法层面，强化学习通过 “行动 — 反馈 — 迭代优化” 的机制，
能够将交易摩擦、风险控制等现实约束纳入奖励函数，相比传统机器学习更贴合真实金融交易场景\cite{bai2025review,qureshi2026deep}。
其中，Liu 等开发的 FinRL 框架已成为金融强化学习领域的主流工具，
该框架采用滚动窗口训练，模型输入为证券的因子和持仓张量，以MLP作为决策模块，
输出包含各类资产与现金的配置权重向量，同时支持 PPO、DQN 等多种算法与多样化奖励设计，
为 Agent 投资决策提供了标准化、可复用的实现方案\cite{liu2021finrl}。

综上，现有研究已验证 Agent 在行为模拟与强化学习决策上的可行性，
FinRL框架也为智能交易提供了成熟工具。
本文将依托上述研究基础，把多Agent行为模拟与FinRL强化学习框架相结合，
构建更贴近真实市场的实验金融模型，用于研究投资者预期共识的定价效应，弥补现有研究缺口。
